# M0-03 实时组环境与实时冒烟测试

## 目标

能够用一条命令启动 `realtime` 分组，使 Kafka、Flink 和 ClickHouse 全部可用，并且有一个可以重复执行的脚本证明 Flink 能够把 Kafka 中的消息写入 ClickHouse。

## 前置任务

M0-01。本任务卡与 M0-02 没有依赖关系，但是两者都会修改 `deploy/images/gateway/`，因此必须在 M0-02 合并之后再开始。

## 依据的设计文档

- `docs/01-环境与部署设计.md` 第 4 节至第 6 节中与 `realtime` 分组有关的内容、第 7.5 节和第 9.2 节。

## 实现范围

1. 在 `deploy/docker-compose.yml` 中增加 `realtime` 分组的四个服务，要求与 M0-01 相同：设置内存上限、时区、健康检查和 profile，端口只绑定到 `127.0.0.1`。
2. 在 `deploy/.env.example` 中增加 `realtime` 分组所需的变量。
3. 新增 `deploy/conf/` 下 Kafka、Flink 和 ClickHouse 的配置文件，Kafka 的两个监听器和 Flink 的检查点目录按照设计文档第 7.5 节配置。
4. 修改 `deploy/images/gateway/`，在镜像中加入 Flink 1.20.x 的客户端，版本号与父工程 `pom.xml` 中的 `flink.version` 保持一致，使网关能够向 Flink 集群提交作业。
5. 扩展 `dp-up.sh`、`dp-down.sh` 和 `dp-health.sh`，使它们支持 `realtime` 分组，并且在启动 `realtime` 之前检查 `core` 分组已经启动。
6. 新增 `deploy/scripts/smoke-realtime.sh`，实现设计文档第 9.2 节的五个步骤。脚本必须可以重复执行。
7. 更新 `deploy/README.md`。

## 明确不做的范围

- 不部署 Flink CDC，不创建任何业务主题和业务表。
- 不编写任何 Java 代码，冒烟测试使用 Flink SQL 完成。
- 不把冒烟测试之外的连接器放入 Flink 的 `lib` 目录。

## 验收命令

以下命令的执行环境均为阿里云服务器，工作目录为 `/opt/dataplatform`，前置条件是 `core` 分组已经启动。

| 序号 | 命令 | 期望输出 |
| --- | --- | --- |
| 1 | `bash deploy/scripts/dp-up.sh realtime` | 四个服务全部启动，退出码为 0。 |
| 2 | `bash deploy/scripts/dp-health.sh realtime` | 逐项输出四个服务的检查结果，全部通过，其中 Flink 的检查结果显示有 4 个可用的任务槽。 |
| 3 | `bash deploy/scripts/smoke-realtime.sh` | 脚本输出每个步骤的结果，最后一行明确说明测试通过，退出码为 0。 |
| 4 | 再次执行 `bash deploy/scripts/smoke-realtime.sh` | 第二次执行仍然通过。 |
| 5 | `docker compose -f deploy/docker-compose.yml exec gateway flink list -m flink-jobmanager:8081` | 没有处于运行状态的冒烟测试作业，证明脚本结束时取消了作业。 |
| 6 | `docker compose -f deploy/docker-compose.yml exec gateway hdfs dfs -ls /flink/checkpoints` | 目录存在，证明 Flink 能够访问 HDFS。 |
| 7 | `bash deploy/scripts/dp-health.sh core` | `core` 分组仍然全部通过。 |
| 8 | `docker stats --no-stream` | 输出全部容器的实际内存占用。 |

## 交付物

- 修改后的 `deploy/docker-compose.yml`、`deploy/.env.example`、`deploy/images/gateway/` 和三个通用脚本。
- `deploy/conf/` 下 Kafka、Flink 和 ClickHouse 的配置文件，`deploy/scripts/smoke-realtime.sh`，更新后的 `deploy/README.md`。

2. 请说明 Flink 镜像访问 HDFS 的实际实现方式，以及所选的 Flink、Kafka 和 ClickHouse 镜像的完整标签。
3. 请确认所选的 Flink 镜像内部使用的是 Java 8。
4. 请反馈消息从写入 Kafka 到可以在 ClickHouse 中查询到的大致延迟。
